Cách Đẩy Lên GitHub Chạy 24/24

Hoàn toàn miễn phí, chỉ mất 2 phút cài đặt

1 Tạo Repository mới trên GitHub

Vào github.com/new, đặt tên (ví dụ: on-tap-12), chọn Public rồi bấm Create repository.

2 Tải toàn bộ thư mục này lên Repo

Bấm uploading an existing file trên GitHub, sau đó kéo toàn bộ file trong thư mục này (bao gồm file index.html, các file môn học và file .nojekyll) thả vào và bấm Commit changes.

3 Bật GitHub Pages (Web 24/24)

Vào tab Settings của repo → chọn mục Pages ở cột trái → tại Branch chọn nhánh main (thư mục / (root)) rồi bấm Save.

Sau 1 phút, trang web sẽ online tại:
https://<username>.github.io/on-tap-12/
